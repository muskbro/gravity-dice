# Gravity Dice

A 3D gravity simulator that tosses dice into a felt tray. Change `g` — Zero-g, Moon, Earth, Jupiter — and watch the bounce, tumble, and face that lands up.

Built with [Three.js](https://threejs.org/) and [cannon-es](https://github.com/pmndrs/cannon-es).

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Controls

- **Roll** or **Space** — throw the dice
- Gravity presets or the slider — 0 to 25 m/s²
- Dice count — 1 to 5
- Slow motion — watch the fall
- Drag — orbit the tray
